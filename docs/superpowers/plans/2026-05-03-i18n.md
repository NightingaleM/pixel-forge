# i18n 多语言支持 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 PixelForge 添加中英双语切换，使用 react-i18next，自动检测浏览器语言 + 手动切换。

**Architecture:** 使用 i18next + react-i18next + i18next-browser-languagedetector，翻译文件按模块组织 key 前缀，全局右上角固定语言切换按钮。注册表数据(StyleRegistry/EffectRegistry)中的文案改为 i18n key，渲染侧通过 t() 解析。

**Tech Stack:** i18next, react-i18next, i18next-browser-languagedetector

- [ ] **Step 1: 创建 `src/i18n/index.ts`**

```typescript
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import LanguageDetector from 'i18next-browser-languagedetector'
import zh from './zh.json'
import en from './en.json'

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      zh: { translation: zh },
      en: { translation: en },
    },
    fallbackLng: 'zh',
    interpolation: {
      escapeValue: false,
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },
  })

export default i18n
```

```tsx
import { useTranslation } from 'react-i18next'

export default function LangSwitch() {
  const { i18n } = useTranslation()
  const isZh = i18n.language.startsWith('zh')

  return (
    <button
      className="lang-switch"
      onClick={() => i18n.changeLanguage(isZh ? 'en' : 'zh')}
    >
      {isZh ? 'EN' : '中'}
    </button>
  )
}
```

**skipRandomNames 改造要点：**
原代码用 `p.name` 匹配中文名来判断跳过随机，改为 i18n key 后 name 变成了 `'style.kaleidoscope.centerX'` 等。应该改为用 `p.uniform` 判断：
```typescript
const skipRandomUniforms = ['uCenterX', 'uCenterY', 'uRotation', 'uAngle']
// ...
```
