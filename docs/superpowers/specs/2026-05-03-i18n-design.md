# i18n 多语言支持设计

## 目标

为 PixelForge 添加中英双语切换，架构上预留其他语言扩展能力。

## 技术选型

**react-i18next** — React 生态事实标准的 i18n 方案。

依赖：
- `i18next`
- `react-i18next`
- `i18next-browser-languagedetector`

## 架构

```
src/
├── i18n/
│   ├── index.ts          # i18next 初始化配置
│   ├── zh.json           # 中文翻译
│   └── en.json           # 英文翻译
├── components/
│   └── LangSwitch.tsx    # 全局语言切换按钮
```

## 关键实现点

### 1. i18n 初始化 (`src/i18n/index.ts`)

- 使用 `i18next-browser-languagedetector` 检测语言
- 检测顺序：localStorage → navigator.language → fallback `zh`
- 在 `main.tsx` 中 `import './i18n'` 确保应用启动前初始化

### 2. 语言切换按钮 (`LangSwitch.tsx`)

- 全局右上角固定定位（`position: fixed`）
- 紧凑的 `中/EN` 文字切换按钮
- 点击在 `zh` / `en` 之间切换
- 当前语言高亮显示
- 样式与项目现有硬边设计一致（无圆角、无阴影）

### 3. 组件改造

所有组件引入 `useTranslation` hook，将硬编码文案替换为 `t()` 调用：
- UI 组件：直接替换字符串
- `StyleRegistry.ts` / `EffectRegistry.ts`：label/description/参数名改为翻译 key，在组件渲染时调用 `t()` 获取文案

### 4. 注册表数据改造

StyleRegistry 和 EffectRegistry 中的 label/description 改为 i18n key：

```ts
// Before
{ label: "Halftone", description: "半色调网点效果..." }

// After
{ label: "style.halftone.label", description: "style.halftone.desc", isI18nKey: true }
```

渲染侧通过 `t()` 解析。这样可以保持注册表数据纯静态，不依赖 hook。

### 5. 语言持久化

i18next-browser-languagedetector 默认将选择写入 localStorage（key: `i18nextLng`），无需额外处理。

### 6. HTML title

`index.html` 中的 `<title>` 通过 React 在 App 根组件中使用 `useEffect` + `document.title = t(...)` 动态设置。

## 不做的事

- URL 路径区分语言（如 `/en/2d`）
- 服务端翻译管理平台
- 翻译文件懒加载（项目小，全量加载即可）
- ICU 复数/日期格式化（项目不需要）

## 扩展性

添加新语言只需：
1. 在 `src/i18n/` 下新增 `{lang}.json`
2. 在 `i18n/index.ts` 的 resources 中注册
3. LangSwitch 组件添加新语言选项
