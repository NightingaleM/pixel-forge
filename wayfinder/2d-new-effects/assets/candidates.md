# 2D 新特效候选清单（18 个主候选 + 观望区）

## 总评

光学/镜头轴全面胜出：top 3 全部出自该轴且双维评分 ≥4，根因是现有 12 风格全部在「改变质感/结构」，而光学特效改变的是「照片的情绪与光线」，这一维度完全空缺。胶片晕光、全息箔、移轴微缩所需基础设施（3-pass FBO 链、hash/value noise 库、brightPoint 亮部扫描）全部现成，边际成本最低。几何轴唯一高性价比候选是小星球（约七成代码可复用 kaleidoscope 极坐标重映射）。印刷轴必须避开半色调/扩散抖动占位，RISO 套色错位是差异化最优解。建议第一批落地：top 3 + 小星球。

## 1. 胶片晕光颗粒 ★TOP1 【光学】

- **一句话**：模拟 CineStill 无防光晕层胶片——高光四周渗出红/金暖色光晕，叠加有机银盐颗粒与细划痕，夜景与人像秒变「电影感」。
- **视觉参考**：
  - 本地图 `assets/refs/halation-cinestill-50d.png`（Cinestill 50D 官方博客头图，焦外高光带暖红晕）
  - https://en.wikipedia.org/wiki/Halation （晕光光学原理）
  - https://www.cinestillfilm.com/ （官方站，FAQ 详述 halation 成因：去除 remjet 防光晕层）
- **实现路径**：3-pass FBO（亮部提取→可分离模糊→合成+颗粒+划痕）。完全复刻 lightshadow 的 renderMultiPass 链；颗粒/划痕直接用 diffusion/crosshatch 的 hash 噪声（划痕=细长低频 hash 条纹）。参数：晕光强度(number)、晕光色(color，默认 Cinestill 红)、颗粒强度/颗粒粗细(number×2)、划痕(toggle)、胶片色调 select(Cinestill红晕/Kodak金暖/Portra粉暖/黑白)。
- **重复风险**：无。现有 12 风格无一涉足色调/光晕域；动画光影是「打光」不是「晕染」，语义正交。
- **评分 5×5**：任何照片（夜景、人像、静物）加它都立刻「贵」起来，惊艳上限最高；参数维度横跨 number/color/select/toggle 四类，骰子随机空间大，可玩性拉满。成本与 lightshadow 同级，无性能风险。

## 2. 全息箔 ★TOP2 【光学】

- **一句话**：把画面变成全息镭射烫印材料——随视角流动的彩虹色带扫过金属箔面，碎冰纹/拉丝/珠光三种质感可选。
- **视觉参考**：
  - 本地图 `assets/refs/holographic-foil-rolls.jpg`、`holographic-foil-rolls-2.jpg`（镭射箔卷材实拍：碎冰纹、点纹、彩虹渐变、珠光——正好对应三个 select 模式的视觉依据）
  - https://cn.dragonfoils.com/products/holographic-foils.html （全息箔纹理谱系，CN 可直连）
  - https://en.wikipedia.org/wiki/Diffraction_grating （衍射光栅=彩虹色散物理原理）
- **实现路径**：单 pass。亮度梯度作伪法线 → 视角相关的光谱色相映射（ hsv(hue=f(梯度,位置,色带角度)) ），叠加 value noise 碎纹调制；深色基底保住「箔面嵌入感」。复用 crosshatch 的 value noise。参数：质感 select(碎冰镭射/拉丝光柱/珠光细闪)、色带密度/角度/强度(number×3)、箔面底色(color)。
- **重复风险**：无。玻璃扭曲是几何位移，本效果是光谱着色，完全正交；也是 18 个候选里竞品 App 最少有的。
- **评分 5×4**：彩虹箔是近年潮玩卡/包装设计的顶流质感，深色或简约主体上效果炸裂（浅色杂图上会糊——desc 文案需提示「深色/简洁照片最佳」）；三种质感 select × 色带角度随机，可玩性高但参数维度略少于晕光。

## 3. 移轴微缩 ★TOP3 【光学】

- **一句话**：一条可调角度的清晰焦带横贯画面、上下渐次虚化+饱和度增益，把俯拍城市/风景变成「玩具小人国」。
- **视觉参考**：
  - 本地图 `assets/refs/tiltshift-bigair-shougang.jpg`（首钢滑雪大跳台：中带清晰、上下虚化、玩具感）、`tiltshift-cablecar-forest.jpg`（秋林索道同款效果）
  - https://en.wikipedia.org/wiki/Miniature_faking （微缩伪造原理与佳作）
  - https://c.m.163.com/news/a/JSCO22BR0514BJET.html （石景山「小人国」实拍教程文，CN 可直连）
- **实现路径**：2-pass FBO（水平+垂直可分离模糊）或保守方案单 pass 13-tap 加权模糊；焦带蒙版由 焦点位置/焦带宽度/倾角 三个 number 驱动，合成时做饱和增益（微缩感的关键是「高饱和+浅景深」错觉）。复用 renderMultiPass。
- **重复风险**：无。散景（#10）同属虚化族但语义不同（散景=光圈形状焦外，移轴=带状景深伪造），两者参数与观感可明确区分。
- **评分 5×4**：风景/城市照片一键「上帝视角」，前后对比冲击极强；焦带三参数+模糊+饱和共 5 个 number 可玩性充足。扣分点：人像/特写照片上效果弱（适用面窄于晕光）。

## 4. 镜头光晕 【光学】

- **一句话**：检测画面最亮点，沿「光源-画面中心」轴布设解析式鬼影、光环、光柱与薄雾，一键电影片头感。
- **视觉参考**：https://en.wikipedia.org/wiki/Lens_flare ；https://www.shadertoy.com/results?query=lens+flare （经典解析式实现谱系，Shadertoy CN 可直连）
- **实现路径**：单 pass + CPU 亮部定位——brightPoint.ts 的 32px 缩略图 luma 扫描是现成的（动画光影的光源 uniform 注入链路照抄），渲染 effect 与批量管线均已接入。鬼影=轴上等比缩放圆/多边形环，hash 变径去机械感。参数：光晕类型 select(标准鬼影/ JJ 式横向蓝条/ 日食光环)、强度、鬼影数量、薄雾(toggle)、色温 color。
- **重复风险**：无。动画光影是「给画面补光」，本效果是「镜头内反射伪影」，正交。
- **评分 4×5**：有亮源的逆光照片上惊艳度直逼 top3，但暗平照片上几乎无效果（惊艳度吃素材）；参数最多、实时拖动反馈最强的一档，可玩性 5。

## 5. 小星球 【几何】

- **一句话**：极坐标立体投影把全景式横图卷成一颗「拇指星球」，反向则成「兔子洞」坠落视角。
- **视觉参考**：https://en.wikipedia.org/wiki/Little_planet_(photography) ；https://en.wikipedia.org/wiki/Stereographic_projection （立体投影几何原理）
- **实现路径**：单 pass。kaleidoscope.frag 的极坐标重映射框架直接改造：r' = zoom·tan(r·k) 或 r' = k/r（兔洞），无折叠；tileMirror 平铺函数可整体搬来处理横向接缝。参数：投影 select(小星球/兔洞)、旋转/缩放/翻转(number×3)。
- **重复风险**：低。与万花筒同属极坐标族，但万花筒=角向折叠复制，小星球=径向反演，用户观感完全两样。
- **评分 4×3**：横幅风景图上效果极具记忆点（朋友圈传播型效果）；但参数仅 3-4 个且人像基本不适用，可玩性中等。成本几乎全场最低（复用约七成 kaleidoscope 代码），性价比选它入第一梯队备选。

## 6. RISO 套色错位 【印刷】

- **一句话**：双色油墨网版印刷风——两三版专色网点按不同网角叠印，故意错位 2-5px，露出纸张底色，zine/riso 复印美学。
- **视觉参考**：https://en.wikipedia.org/wiki/Risograph ；https://halftone.pro/ （在线网点工具，票面指定参考源）
- **实现路径**：单 pass。亮度+色度拆两三层油墨（油墨 1/2 各一个 color 参数），每层用现有 halftone.frag 的旋转网屏公式（不同网角、不同错位 dx/dy），叠加纸纹 value noise。参数：油墨色(color×2)、错位量(number)、网角差(number)、纸色(color)。
- **重复风险**：**中**——半色调已占「单色网点」位、波普已占「高饱和撞色」位。差异化护城河：限色专色油墨（2-3 色封顶）+ 套印错位 + 网角互差 + 纸底色，四件事同时做才成立；若只做网点会撞半色调，验收时需对照。
- **评分 4×4**：riso 风在独立设计圈是硬通货，人像海报效果尤其好；双色 color 均入种子码随机，配色抽奖玩法天然成立。

## 7. 棱镜彩虹色散 【光学】

- **一句话**：RGB 三通道沿径向/对角分离采样，高对比边缘拖出彩虹镶边与紫边——TikTok「钻石棱镜」同款。
- **视觉参考**：https://en.wikipedia.org/wiki/Chromatic_aberration ；https://en.wikipedia.org/wiki/Dispersion_(optics)
- **实现路径**：单 pass。三次 texture2D 采样按 (uv ± dir·amount·channel) 分离（dir=径向或对角，模式 select）；「紫边增强」模式= luma 梯度检测高对比缘再叠紫。参数：色散量(number)、方向角(number)、模式 select(径向色差/对角色散/紫边增强)、色散色偏(color)。
- **重复风险**：无。玻璃扭曲是位移，这里是纯通道分离。
- **评分 4×4**：短视频平台验证过的流行语法，边缘彩虹在建筑/玻璃幕墙照片上极出彩；实现是全场最简单之一（10 行核心），性价比极高。

## 8. LOMO 暗角漏光 【光学】

- **一句话**：塑料玩具相机美学——浓重暗角 + 边缘一道漏光色斑 + 交叉冲洗偏色，随手拍变「胶片日记」。
- **视觉参考**：https://en.wikipedia.org/wiki/Lomography ；https://en.wikipedia.org/wiki/Cross_processing （交叉冲洗色谱）
- **实现路径**：单 pass。径向暗角（形状 select 圆形/方形）、漏光=某一边缘的羽化色带（漏光侧 select + 漏光色 color + 噪声扰动边缘）、色调=提亮阴影+绿/青偏移+饱和增益。参数：暗角强度、暗角形状 select、漏光侧 select、漏光色 color、漏光强度、偏色强度。全解析，零噪声依赖也行（噪声羽化更自然）。
- **重复风险**：无。与晕光的差异：晕光=高光局部渗色（需 blur），LOMO=全局暗角+边缘漏光（无 blur），观感与实现均不同；若担心用户混淆，desc 文案明确「边角漏光 vs 高光晕染」。
- **评分 4×4**：复古滤镜最大众化的入口款，任何照片都吃；实现成本全场最低（单 pass 纯解析），但惊艳上限略低于 top3（大众款缺新奇感）。

## 9. 变形宽银幕 【光学】

- **一句话**：anamorphic 镜头签名——画面横向压缩拉伸、亮点拖出水平蓝条、椭圆暗角 + 2.39:1 黑边，电影感三件套。
- **视觉参考**：https://en.wikipedia.org/wiki/Anamorphic_format ；https://www.shadertoy.com/results?query=anamorphic （横向蓝 flare 经典 shader）
- **实现路径**：单 pass 起步：横向 UV 缩放（1.0-1.33）、椭圆暗角、黑边 letterbox(toggle)；蓝条用「沿光源行方向各向异性多次采样」近似（配合 brightPoint 光源位）或升级 2-pass 横向模糊更纯。参数：拉伸量、蓝条强度、蓝条色 color、黑边 toggle、暗角强度。
- **重复风险**：低，但需主动错位——镜头光晕(#4)的「JJ 式横向蓝条」模式与本效果重叠：建议光晕以鬼影/光环为主、蓝条归属本效果，二票只上一个时再合并。
- **评分 4×4**：夜景霓虹/车流照片一键「院线预告片」；黑边 toggle 的裁幅玩法在社交媒体分享场景实用性强。

## 10. 散景焦外 【光学】

- **一句话**：真实光圈形状的大面积焦外光斑（圆/六角/椭圆可切），焦区外的一切灯光都化成奶油般的 bokeh 盘。
- **视觉参考**：https://en.wikipedia.org/wiki/Bokeh （含光圈形状与焦外成像对比图）
- **实现路径**：2-3-pass FBO：降采样(×2)→光圈形状核变半径模糊（焦区蒙版：中心圆或线带）→升采样合成。形状在核掩码里做（圆/正六边形/椭圆=本效果独有卖点）。**性能风险中**：2048 全幅大核采样开销大，核 pass 必须半分辨率跑；实时预览可行，批量 20 行耗时会上升（票面要求标注——这是全表唯一需降采样兜底的候选）。
- **重复风险**：无（与移轴的区别见 #3）。
- **评分 5×3**：夜景灯光人像上惊艳度 5 星（光斑盘是相机价格的象征……）；但形状/大小/焦区三个参数玩完就到头，且吃 GPU，可玩性与成本均让位。

## 11. 等高线地图 【结构】

- **一句话**：把亮度当地形海拔，等间距切出地形图等高线，可叠地形高程色带——风景照秒变科考地图。
- **视觉参考**：https://en.wikipedia.org/wiki/Contour_line （含地形图样式与高程色带）
- **实现路径**：单 pass。luma→海拔量化，相邻固定偏移采样差分检测等值线（**不用 fwidth**：WebGL1 需 OES_standard_derivatives 扩展，保守方案零依赖）；高程色带 select(墨线单色/地形彩带/日照晕染)。参数：等高距(number)、线宽(number)、色带 select、平滑度(number)。
- **重复风险**：低。素描/网纹提取的是「结构线」，本效果是「量化等值线」，拓扑图观感独一份。
- **评分 4×3**：山地/建筑照片出片即壁纸，知识感拉满；但对低对比照片效果平庸，参数维度中等。

## 12. 扫描仪故障 【光学】

- **一句话**：扫描仪卡纸瞬间的美学——横向条带错位、RGB 行分裂、滚降亮条与随机尘点，glitch 爱好者专用。
- **视觉参考**：https://en.wikipedia.org/wiki/Glitch_art （scanline/glitch 谱系；搜 "scanner glitch art" 图片可得大量实例）
- **实现路径**：单 pass。横带 hash 位移（带内同 offset、带间随机）、行级 RGB 错位、亮度滚降条（位置 select 上/中/下）、尘点=稀疏 hash 斑。参数：条带密度、错位量、RGB 分裂、尘点(toggle)、滚降光条 select。
- **重复风险**：无（棱镜色散是全局通道分离，这里是条带级撕裂）。
- **评分 3×4**：亚文化圈层惊艳（专辑封面/蒸汽波场景刚需），大众观感两极；但参数随机性玩法极多（骰子一摇一个故障款式），可玩性 4。

## 13. 漫画分格 【结构】

- **一句话**：把照片切成漫画分格画布——沟槽留白+粗墨描边，格内可叠 Ben-Day 网点，一键四格/九格漫画页。
- **视觉参考**：https://en.wikipedia.org/wiki/Comics （分格 vocabulary；Roy Lichtenstein 波普即 Ben-Day 网点+分格的组合先例）
- **实现路径**：canvas2d（renderMode:'canvas2d'，AsciiCanvasRenderer 全链路先例：离屏消费+逐 cell 绘制，可导 SVG）。drawImage 切格+沟槽+描边；Ben-Day 点用 cell 级 fillRect 网格（非逐像素，2048 下性能可控）。参数：分格 select(2×2/3×3/4×4/条漫)、沟槽宽度、描边宽度、网点(toggle)、网点大小。
- **重复风险**：低。半色调是全幅网点，这里是「分格构图+可选格内网点」，组合语义不同。
- **评分 4×3**：社交传播型玩法（四格叙事模板感强）；但构图逻辑是 canvas2d 全新代码面，实现工作量全表偏大，且格内网点需与半色调做观感区隔。

## 14. 铜版蚀刻 【印刷】

- **一句话**：钞票雕版美学——线方向跟随画面明暗梯度的流线刻痕，暗部叠 45° 交叉层，人像变「第五套人民币」。
- **视觉参考**：https://en.wikipedia.org/wiki/Engraving ；https://en.wikipedia.org/wiki/Mezzotint （雕版/铜版美柔汀谱系）
- **实现路径**：单 pass。crosshatch 的网格 cell 范式照搬，但每 cell 刻线方向=亮度梯度旋转 90°（流线感的关键），暗部按阈值叠加第二层交叉线。参数：线距(number)、深度层数(number)、走向 select(跟随轮廓/水平/环形)。复杂度中高（方向场抖动需调教），建议出票前做 1 页 spike。
- **重复风险**：**中**——素描/网纹底稿已占「线条还原」位。差异化=动态走向跟随（素描是固定方向笔画）+ 钞雕密度感；若走向参数只有固定方向就与网纹撞车，验收标准必须含「轮廓跟随」。
- **评分 4×3**：钞雕人像的辨识度极高（惊艳 4）；参数可玩中等，调教成本高拉低推荐度。

## 15. 二维码马赛克 【文字】

- **一句话**：画面量化成黑白模块网格并植入三枚定位角标与 timing 线——远看是装饰画，近看「像真的一样」的二维码马赛克。
- **视觉参考**：https://en.wikipedia.org/wiki/QR_code （模块/定位标/静区结构图）
- **实现路径**：单 pass。N×N 网格 luma 二值化 + hash 撒点做「数据模块」纹理 + 三角定位块/定时线几何绘制 + 白色静区边框。参数：模块粒度(number)、深/浅模块色(color×2)、反相(toggle)、静区宽度(number)。注明 desc：装饰艺术非可扫真码（诚实标注，避免用户拿去扫）。
- **重复风险**：低。文字栅格是「格内写字」，这里是「抽象模块拼合」，观感正交。
- **评分 3×4**：惊艳度中等（新奇>美），但极简黑白双 color + 粒度随机是天然的极简海报生成器，可玩性 4；实现极简（半天量级）。

## 16. 复印机 【印刷】

- **一句话**：第 9 次传阅的 zine 复印件——高反差碳粉成块、斑驳底灰、边缘焦黑，地下杂志质感。
- **视觉参考**：https://en.wikipedia.org/wiki/Photocopier ；https://en.wikipedia.org/wiki/Xerography （碳粉成像原理）
- **实现路径**：单 pass。低频 value noise 斑驳调制亮度阈值（成块而非抖动纹理——与扩散抖动的本质差异）、梯度边缘加深、细颗粒。参数：浓度(number)、斑驳度(number)、边缘焦黑(toggle)、双色碳粉 toggle+accent color。
- **重复风险**：低-中。扩散抖动=误差扩散灰阶仿真；复印机=噪声阈值**丢灰阶**成块，观感更糙更狠；desc 需写明差异。
- **评分 3×3**：特定审美（朋克/独立出版）很香，大众向平平；实现便宜，作为印刷轴补充位。

## 17. 盲文点阵 【文字】

- **一句话**：画面转译成盲文凸点金属板——每个 2×4 点位按亮度编码起伏，触觉视觉化的无障碍美学。
- **视觉参考**：https://en.wikipedia.org/wiki/Braille （六/八点点阵编码表）；https://en.wikipedia.org/wiki/Refreshable_braille_display （凸点硬件实拍）
- **实现路径**：单 pass。cell 网格（2×4 点/格），亮度→8bit 点型（映射逻辑借鉴 Unicode braille 码表的直觉），每点画高光偏移圆（伪凸起）。参数：点位粒度(number)、板材色/点色(color×2)、凸点高光强度(number)。
- **重复风险**：**中**——点彩已占「圆点重构」位。差异化=微点阵+编码感+金属凸点质感（点彩是绘画性彩色圆点，本效果是工程性单色微点），必须做出「板」的材质感才立得住。
- **评分 3×3**：概念惊艳但受众窄；随机重玩价值一般，入列作文字轴广扫保底位。

## 18. 鱼眼液化 【几何】

- **一句话**：Photoshop「球面化/挤压/旋转扭曲」三件套——全局径向鼓包、内吸或漩涡，交互拖拽感最强的几何玩具。
- **视觉参考**：https://en.wikipedia.org/wiki/Fisheye_lens （鱼眼畸变样片）；https://en.wikipedia.org/wiki/Distortion_(optics) （桶形/枕形畸变）
- **实现路径**：单 pass。径向 r'=r·(1±k·smoothstep(R,0,r)) 三种 select 模式，中心/半径/强度参数。纯公式，零新基础设施。
- **重复风险**：低。玻璃扭曲=噪声位移场（局部随机），本效果=全局相干径向场，参数语义完全不同；与万花筒更不沾边。
- **评分 3×3**：老少咸宜的娱乐向效果（哈哈镜），惊艳度上限一般；胜在实现零成本。
