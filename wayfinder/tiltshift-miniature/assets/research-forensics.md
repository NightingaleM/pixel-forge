## 0. TL;DR

1. **旧版从未产生过任何真实模糊。** blur shader 的采样偏移是 UV 单位而非 texel 单位（`vUv + uDir*(i*3)`，uDir=(3,0) → 偏移 9/18/27/36 个 UV 整数单位），[0,1] 的 UV 域全部越界、被 CLAMP_TO_EDGE 钳到画面边缘行列。每轮 pass 实际执行的是「22.7% 保留自身 + 77.3% 混入该行/列两端像素均值」，5 轮后原图信息权重 0.227¹⁰≈3×10⁻⁷——注释里的「σ≈20px 重虚化」是纸面意图，**有效模糊半径 = 0**。headless Edge 实跑复刻探针实测：64×64 中心白块（能量 4080）经原版 shader 5 轮后全图能量 = 0（真高斯模糊能量守恒应 ≈4080）；单 pass 后白块处灰度 = 58 = 0.227×255，与「行端点涂抹」公式逐位吻合。
2. 三条病理假设裁决：**H1「高斯涂抹」证伪并改写**（不是涂抹，是更空的两类形态——满糊区=边界调和色场、过渡带=与调和场的半透明混合，即用户看到的「蒙凡士林」）；**H2「爬升错」方向证实但机理改写**（真问题不是三明治一刀切，而是「假糊 + 用 alpha 混合模拟模糊梯度」——正确做法是模糊半径本身随离焦距离渐变）；**H3「强度不足」结论成立但数值前提证伪**（不是 σ≈20px 太小，是 σ=0）。
3. scene2「模糊几乎不可见」矛盾的解释：见 §1.5——满糊区被替换成边界色场，恰落在天空/路面等低频内容上「看似糊了」；过渡带是「雾感」而非「失焦感」；且 scene2 素材经鉴定是**城市街景（巴西圣保罗市政剧院一带俯拍）而非票内所记「俯拍山景」**，信源冲突已如实记录。
4. 「高斯 vs bokeh 盘是否关键分水岭」：**不是**（详见 §5）。真正的分水岭 = 真实的半径渐变 + 足够剂量（满糊晕开宽 2–5% 画高）+ 饱和/对比增益 + 俯角素材先验。bokeh 圆盘核是可选加分项。

## 1. 旧实现病理定量结论

### 1.1 代码事实（wayfinder/2d-new-effects/assets/sampler/sampler.html）

| 位置 | 内容 |
|---|---|
| L73–83 | blur 片元：9-tap 高斯权重（w0=0.227027…w4=0.016216，σ≈1 的离散高斯），采样偏移 `o = uDir*(i*3.0)`，i=1..4 → ±9/18/27/36（单位：UV） |
| L223–231 | blurPass：`uniform2f(uDir, dx, dy)`，tiltshift 调用传 (3,0)/(0,3) |
| L243–253 | renderTiltshift：src→fboA 直通，5 轮 H/V blurPass，最后 mix(sharp, blur, blurAmt) 合成；`uBand=(BAND_Y, BAND_TILT)` 默认 (0.50, 0.10) |
| L146–158 | tiltshift 片元：`band=(vUv.y-0.5)+(vUv.x-0.5)*0.10`；`blurAmt=smoothstep(0.03,0.28,|band|)`；饱和增益 `mix(luma, col, 1.5-0.1*blurAmt)`；`pow(col,0.92)*1.05` |

### 1.2 根因实锤：UV/texel 单位错位

shader 内没有 `1.0/uRes` 归一化（同文件 holofoil/prism 都正确使用了 `px=1.0/uRes`，唯独 blur 漏了），`vUv ± 9.0` 远超 [0,1]，CLAMP_TO_EDGE 下 8 个外点 tap 全部落在画面边缘：

- H pass 实际语义：`out(x,y) = 0.227·in(x,y) + 0.3865·in(0,y) + 0.3865·in(W-1,y)`（本行左右端点）
- V pass 同理（本列上下端点）
- 5 轮（10 pass）后：原图信息权重 0.227¹⁰ ≈ 3.3×10⁻⁷，blur 图 ≈ 由四条边界行列的嵌套平均构成的**超平滑调和色场**

探针验证（headless Edge + SwiftShader，逐字复刻 shader，64×64 黑底中心白块）：

| 探针 | 白块能量（直读=4080） | 结论 |
|---|---|---|
| S0 直读（sanity） | 4080 | 管线正常 |
| A 原版 shader × 5 轮 | **0** | 无模糊发生；能量被边界（黑）吞掉。若按注释意图（±9..36 texel）工作，能量应守恒铺开为灰雾 |
| B 修正为 texel 语义 × 5 轮 | 992 | 真实大半径模糊的形态（能量向边界 clamp 稀释） |
| C 原版 1 pass | 白块处 58 = 0.227×255 | 逐位吻合「行端点涂抹」公式 |

### 1.3 「σ≈20px」注释的来历与实际有效模糊半径

若 uDir 按 texel 语义（偏移 = 9/18/27/36 px）解读：单 pass 等效高斯 σ = √(2Σwᵢ·offᵢ²) = √231.2 ≈ **15.2px**，5 轮同向串联 σ_eq = 15.2×√5 ≈ **34px**——注释写 σ≈20px 本身就低估了三分之一（对 960 画布）。但由于 §1.2 的单位错位，**实际有效模糊半径 = 0px**。视觉分析在成品上估出的「顶缘有效 σ 5–15px」并非模糊，而是「细节被调和场替换后淡出」被误读为柔化。

### 1.4 三条病理假设裁决

| # | 假设 | 裁决 | 修正后的病理表述 |
|---|---|---|---|
| H1 | 模糊本质错：高斯涂抹 vs bokeh 盘，涂抹感是失败主因 | **证伪（部分）** | 旧版连高斯涂抹都不是。两种退化形态：满糊区 = 边界调和色场（细节「淡出/消失」，无晕开过程，无光斑）；过渡带 = 原图与色场的 alpha 混合 = 「蒙凡士林/雾」观感的真实机理。bokeh 缺失只是第三层缺失，非主因（见 §5） |
| H2 | 模糊爬升错：焦带外一刀进满糊（三明治） | **方向证实，机理改写** | smoothstep(0.03,0.28) 本身有 25%H/侧 的过渡带，并非一刀切；真正的爬升错误是**用「固定模糊图 × 权重混合」模拟梯度**——过渡带呈现双重曝光/半透明感而非光学离焦。正确做法：模糊半径本身随 |band| 单调渐增（多级半径/金字塔模糊），参考图正是这种形态 |
| H3 | 强度不足：σ≈20px 缩放观看仅剩轻度柔化 | **结论成立，数值前提证伪** | 有效 σ=0 而非 20px。即便修好单位错位，σ=34px（960 画布）折 5.3% 画高，与参考图满糊晕开宽 2–7%H 同量级，方向可行——但必须配合 H2 的半径渐变与饱和增益才成立 |

另有两点此前未被假设覆盖的独立病理：
- **素材错配（car 版）**：平视近距「汽车英雄照」，车占画面 62%×53%，无俯角无纵深，车牌文字可读提供真实尺度锚点——该素材在任何参数下都只能读成「浅景深车照」，不可能读成玩具（主因排序中列第一位）。
- **倾斜不可读**：BAND_TILT=0.10（5.7°）在低模糊对比下视觉完全读不出（两版成品分析均实测「近乎水平」）；参考图倾角 2–10° 是搭配高模糊对比才成立的。

### 1.5 scene2「模糊几乎不可见」矛盾的完整解释

「代码注释 σ≈20px 重虚化」与「视觉核验几乎看不到模糊」两者都「对」，因为它们说的是两回事：

1. 代码确实跑了 10 个 blur pass（不是渲染失败），但每个 pass 做的是行列端点涂抹，**没有任何像素邻域卷积发生**。
2. 满糊区（|band|>0.28，即上下边缘条）被替换为边界调和色场：顶部是云天、底部是沥青路面——**内容本征低频，色场替换与「糊了」不可区分**，「看起来处理过了但说不出所以然」。
3. 全图仅有高频内容的角落（右上树丛、右下摊位）显形出「细节消失」，被视觉核验读为「8–20px 的轻度柔化」——实为淡出。
4. 过渡带（每侧 25%H）是原图与色场的 alpha 混合，观感=整体雾化/对比下降，无方向性晕开，低于「失焦」的认知阈值。
5. **素材鉴定冲突（如实记录）**：票 03 记 scene2 为「用户提供的俯拍山景」，但成品内容经鉴定为**巴西圣保罗市政剧院与 Anhangabaú 谷地俯拍城市街景**（高机位、大量微小行人车辆，其实是优秀移轴题材）。两说矛盾，供主会话裁决；不影响上述病理结论——无论山景还是街景，blur 均未发生。

### 1.6 波及面提示（不在本票范围，仅记录）

renderHalation（L233–241）使用同一个 broken blurPass（3 轮）做晕光扩散——其「大半径光晕」同样是边界场而非真扩散。晕光候选现留在候选池未交付，若重启须先修 blur 核。

## 2. 参考图观感要素清单（量级基准）

来源：tiltshift-bigair-shougang.jpg（1080×720，首钢大跳台）、tiltshift-cablecar-forest.jpg（1080×721，秋林索道），逐张视觉定量分析。**口径约定**：H=画高；「晕开宽 w」= 可辨认细节被摊开的宽度（≈2σ）；「焦带宽」= 全清晰核心带（宽义含近清晰区另注）。

| 要素 | 首钢大跳台 | 秋林索道 | **设计基准（横幅）** |
|---|---|---|---|
| 焦带中心位置 | 0.72–0.76H（跟主体） | 0.40–0.45H（跟主体） | 跟主体走，常见 0.40–0.75H，不默认居中 |
| 焦带宽度 | 10–15%H（宽义 25–30%） | 20–25%H | **12–25%H** |
| 焦带倾角 | 2–5°（近水平） | 5–10°（沿等高线微翘） | 常规 **≤3°**；沿等距线/水线时可 10–13°（见 §3 海滩图） |
| 满糊晕开宽 w（顶） | 0.5–1%H（顶为云天，低频显形受限） | 4–7%H（树梢高频） | 高频内容处 **2–7%H**（σ≈1–3.5%H）；低频区不可作标定依据 |
| 满糊晕开宽 w（底） | 1–2%H | 3–6%H | 同上；底可略大于顶（1.2–1.5:1） |
| 模糊梯度形态 | 单调 S 形渐增，单侧过渡 15–20%H | 单调渐增，单侧 10–18%H | **半径单调渐增**（非 alpha 混合），每侧过渡 8–20%H，smoothstep 型缓入缓出 |
| 最糊处状态 | 细节 90% 融失，大尺度结构（云团/明暗分区）仍可读 | 树冠塌缩为色块，仅存颜色分布 | 验收口径：细节消失但**大结构色块可读**，不塌成均匀色 |
| 失焦形态 | 高光=柔和高斯雾斑，**无硬边 bokeh 盘**，明暗对称 | 车厢晕成 15–25px 圆形软斑，叶隙光斑小而软 | 软边圆斑即可；硬边盘非必需（见 §5） |
| 饱和度增益 | +30–50%（天空 S 0.60–0.75） | +25–40% | **+12–18 点（PS 饱和度口径）或 1.25–1.5×**，清晰带略强于糊区 |
| 对比度增益 | +15–25% 且带 clarity | +10–20% | **+10–20% + 焦带内微反差/锐化**（「塑料漆面感」来源） |
| 色偏 | 略偏冷青 | 近中性略暖 | 无固定偏色；不加暖（素材光已足） |
| 拍摄俯角 | 15–25°（无人机 80–150m） | 15–25°（中景）/30–45°（近景） | 素材先验：**>25° 稳，45–60° 最佳**（web 多源一致） |
| 其他微缩线索 | 长焦压缩、无尺度锚点（无可辨人车）、均匀重复小元素、干净背景、轻微暗角 | 主体极小（车厢 10–20px）、糖果色、漫射均匀光、树冠绒面质感 | 均衡漫射光加分；强雾/大气透视减分 |

**横竖幅通则**（判定图分析+调研收敛）：焦带永远垂直于场景深度轴；横幅一点透视街景→水平带；竖幅纵深街道→仍是水平带（深度轴沿竖向），竖幅同百分比对应更多绝对像素，满糊半径须「百分比 + 绝对像素」双上限卡（>45px 重复纹理融成涂抹感），竖幅下缘（近景人脸侧）比横幅保守 1/3，上缘（天空侧）可更激进。

## 4. Web 调研发现（中英文源）

搜索路径：内置 WebSearch 配额尽（429 Monthly Limit Exhausted）→ 按全局降级规则单向切智谱 MCP（search_pro + search_pro_sogou），未回切。

1. **俯角先验**：多源一致收敛「30°–60° 俯角」为后期移轴的标准前提（太平洋电脑网两篇独立问答；AI 绘图社区把 bird's-eye/60° downward 列为移轴提示词必备项，缺了「AI 默认平视、微缩感直接消失」）。平视/人物特写列为禁止场景，「清晰带定位失准、人为痕迹暴露」。
2. **清晰带宽度**：PS 模糊画廊流程给「画面垂直高度的 15–25%」与「8–12%」两说（不同作者口径），与参考图实测 10–25%H 一致收敛。
3. **模糊半径量级**：中文实操教程给「顶部 25–40px、底部 35–50px」「20–50px」（未注明分辨率，按常规 1080–1920 宽折算 ≈2–5%H），且明确「底部略大于顶部以匹配真实移轴的非对称衰减」；模糊强度要求「从清晰带边缘向上下线性/渐变递增」。毛星云《十种模糊算法总结》的 Tilt Shift Blur 工业实现 = Gradient-uv 掩码（pow(abs(centerY−Area), Spread)）控制区域模糊强度。
4. **饱和/对比惯例**：「全图饱和 +12–18 点、清晰区单独加亮 5–8%」（PS 流程）；AI 社区一致「slightly oversaturated, crisp shadows, **no atmospheric haze**（大气晕染破坏微缩世界封闭感）」；「studio lighting」联想模型摄影棚。
5. **什么素材出效果**：城市街区、立交桥、港口码头、游乐场 + 「多层纵深 + 规律性重复元素（整齐车辆、等距窗格）」；宁波三江口夜景案例（江面船与桥=玩具）证明水面/夜景亦可。
6. **什么会穿帮**：平视/低角、人物特写、清晰带切在主体半途（「半糊撕裂」）、半清半糊的文字招牌、清晰的可辨尺度锚点（大人脸、可读车牌、可辨地标）、过渡带硬边、（AI 语境）bokeh balls 反被列为负向词——球状散景堆叠会破坏「移轴=单向渐变」的预期。
7. **真假移轴之辨（对 H1/§5 关键）**：真实摄影师观点（钱江晚报采访）：「镜头模糊是景深造成的、模糊区域有光斑（焦外）；PS 模糊没有光斑」——即社区确把「焦外光斑」当真假分界。但 DCFever/Fstoppers 的更精确表述是模拟的两大差距=「散景质感 + **深浅不一的模糊程度**（半径渐变）」；ZOOOP 术语站直说「模型感可以（用渐变模糊伪造），软件难以伪造的是透视矫正」。而本项目的两张参考图经鉴定本身即数字模拟（软晕、无硬边盘、对称明暗扩散）——**被用户认可的「正确答案」并不含 bokeh 盘**。

---

## 5. 「高斯 vs bokeh 盘是否关键分水岭」——明确回答

**不是分水岭。** 判据三条：

1. **实证**：两张参考图（用户认可的正确答案）高光均为软边晕斑、无硬边 bokeh 盘，且大概率本身是数字模拟（PIL/GIMP 式渐变高斯的产物）。若 bokeh 盘是认可前提，这两张不该被选中。
2. **社区**：「渐变模糊就够骗过多数场合」是主流实操共识；散景质感只是进阶差异项，且在部分语境（球状散景堆叠）反而负面。
3. **分场景收益**：4 张判定图里只有强点光源内容（纽约对向车灯、黄昏水面反光）从圆盘核显著获益；河内硬光的湖面/玻璃反光用盘核会产成扎眼亮饼（该张明确高斯优先）。

真正的分水岭（按权重）：**① 模糊必须真实发生且半径随离焦单调渐变**（对旧版是 0→有的质变，对 alpha 混合是「双重曝光感→光学离焦感」的质变）；**② 剂量**（满糊晕开宽 2–5%H，细节融失但大结构色块可读）；**③ 饱和/对比/带内锐化的「塑料漆面」色彩分离**；**④ 素材俯角>25°**。bokeh 圆盘核列为 P2 可选开关（如「光斑形状」参数，圆盘/五边形/软高斯），在点光源场景解锁。

## 6. 给实验室样张与规格锁定的设计输入（下一票接口）

1. **先修 blur**：offset 必须乘 `1.0/uRes`（texel 语义）；修后单 pass σ≈15px、5 轮 σ≈34px（960 画布）可作「重糊档」。修后须用 §1.2 探针方法回归（能量守恒断言）。
2. **半径渐变实现**：多级半径金字塔（3–5 档：σ = k·f(|band|)，k 单调递增至满糊 σ_max），档间沿 band 方向插值；放弃 sharp/blur 二图 alpha 混合（可保留 ≤15% 的微量混合掩盖档间跳变）。
3. **参数默认值建议**（归一化到画高 H；横幅）：焦带中心随主体（0.45–0.60 常用）、带宽 18%H、倾角 0°（可选 ±13° 斜带模式）、σ_max 上 1.5–2%H / 下 2–3%H、过渡带每侧 12–18%H、smoothstep 缓动；竖幅下缘 σ_max×0.65 且绝对半径 ≤45px 封顶。
4. **色彩链**：饱和 +12–18 点（Vibrance 语义优先）、对比 +10–20%、焦带内 clarity +10–15、糊区饱和 −5~−10；不加暖色温。
5. **防伪影**：过渡带避免切过文字招牌（自动或参数避让）；天空/雾霾大渐变区加 0.3–0.5px dither 防 banding；阴影区先提亮再糊。
6. **验收口径**：满糊区「细看只剩色块、退远仍读得出大结构」；过渡带「无双重曝光感」；成品缩至 50% 观看时上下缘失焦可一眼识别（旧版在此口径下完全不可见）。
