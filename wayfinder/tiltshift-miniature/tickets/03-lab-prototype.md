- **关键发现**：
  1. **六角光圈在 4 张白昼素材上不可见**（含 hiGlow=0.85 压力测试）：点光源被路面反光拉成光柱、尺寸小于盘缘柔边；强偏置副作用=天空白饼+暗部颗粒。与 01 票「bokeh 盘非分水岭」预判一致。形状 select 的观感价值=负，是否保留入正式参数面由用户裁决。
  2. **B 路线特性**：高光保真最好（能量保留式扩散），但全分螺旋的逐像素 jitter 在糊区形成磨砂颗粒，竖幅大糊区最明显（bazaar 目检 4-6/10，主要扣分项）。
  3. **C 路线特性**：顶区最干净（重糊层接管），但 disc/heavy 交叉带（r=6-8%）有半透明重影（bazaar 下过渡目检可见）。
  4. **A 路线特性**：nyc 目检「真实离焦感成立、无三明治/硬边/振铃」，下半过渡略陡、带内微反差偏软；高光层默认 0.35 不够撑盘（光斑不膨胀）。
  5. 修掉旧版病理：offset 已全 texel/UV 正确（能量探针通过），半径随带距单调渐变（pow1.5），无「满糊区=边界色场」。

## Resolution（用户终判 2026-10-13，合格门通过）

**判定：A 金字塔混合路线胜出，默认参数达成「一眼玩具感」合格线。**

1. **默认参数定稿**（用户纽约图实调，全图统一，已设为 [lab.html](../assets/lab/lab.html) 全局 BASE）：
   `bandY=0.5 / bandW=0.02 / bandTilt=0 / maxBlurTop=6% / maxBlurBottom=5% / feather=0.34 / hiGlow=0.5 / sat=1.5 / con=1.3 / clar=0.5 / vig=0.25 / warm=0.5 / dith=0.006`。
   特征：极窄焦带（2% 短边）+ 长过渡（34%）+ 上下独立满糊半径 + 浓色彩（饱和 1.5/对比 1.3/带内加锐 0.5/暗角 0.25/**微暖 0.5 要**/抖动 0.006）。
2. **光圈形状参数砍除**：六角在 4 张白昼素材不可见（用户体感「差异不明显」+ hiGlow=0.85 压力测试仍不可见且副作用大）——正式参数面无形状 select，光圈核固定圆。lab 工具页保留 select 仅作实验。
3. **竖幅**：默认 0° 倾角（水平带），倾角范围放开 ±90° 供用户自调（90° 竖带技术成立无伪影，但默认不带——目检微缩感弱化为「钥匙孔感」）。
4. **参数语义修订**（本轮用户报障驱动的修复）：
   - 「上缘/下缘满糊 R%」两个独立滑杆（原「R%+下/上比值」交互反直觉，已废）；
   - **上下完全解耦**：层级阶梯按各像素本侧满糊值归一 + 深层/重糊层上下两份独立加轮——sweep 实测只动一侧时另一侧渲染逐位不变（|Δ|=0.000）；
   - **R% 全程有效**：深层动态加轮（每 4% 一轮，1-6 轮），顶缘细节能量随 2→25% 单调降（1.6→1.0）——修掉了初版「金字塔 4 层封顶、R% 大端无效」的结构缺陷；
   - 过渡带滑杆上限 0.35→0.70（用户要求）。
5. **出局记录**：B 全分螺旋 disc——大半径欠采样噪声随 R% 反增（边缘能量 3.6→6.0），只作质感上界参照；C 半分 disc+重糊——disc/heavy 交叉带（r=6-8%）重影鼓包（3.1→4.2→回落）+ 顶区仍依赖固定重糊层。
6. **渐进模糊语义确认**：半径曲线 `pow(smoothstep(0,feather,带距),1.5)` 单调渐增 + 层间三角权重插值，离焦带越远越糊，非分层切带。
7. 资产：[lab.html](../assets/lab/lab.html)（工具页）/ [static.html](../assets/lab/static.html) + [out/](../assets/lab/out/)（对照图 57/57 断言）/ [sweep.mjs](../assets/lab/sweep.mjs)（解耦+单调验证）/ [export-static.mjs](../assets/lab/export-static.mjs)。
8. 智能焦带估计收在初版（y 偏差 ≤0.18、倾角偶误判，nyc -16°），按票面「估错可手调」不阻塞；正式置信守门与回退在 04/05 落地。
